# Gen X Soft Club — Art Direction Skill

## Purpose

Use this skill whenever designing, implementing, reviewing or extending a Gen X Soft Club experience.

The goal is NOT to create a website that merely talks about Gen X Soft Club.

The digital product itself must feel like an artifact from the Gen X Soft Club universe.

The user should feel that they are entering the aesthetic rather than reading about it.

Core concept:

> ENTER THE SOFT CLUB.

The experience should feel like a late-1990s / early-2000s vision of a calm, metropolitan, technological future.

---

# 1. CULTURAL PRIORITY

For editorial experiences, prioritize:

1. MUSIC — 50%
2. FASHION — 30%
3. PHOTOGRAPHY / DESIGN / CULTURE — 20%

Music is the emotional center.

Fashion gives the culture a physical identity.

Photography, graphic design, architecture and technology create the atmosphere surrounding both.

Do not treat these percentages as rigid layout measurements. They define editorial importance.

---

# 2. CORE VISUAL LANGUAGE

The experience should communicate:

- late-90s futurism
- metropolitan life
- quiet technology
- underground music culture
- editorial fashion
- analog/digital transition
- physical media
- urban solitude
- public transportation
- airports
- subway systems
- industrial architecture
- translucent electronics
- printed magazines
- scanned documents
- imperfect photography
- experimental editorial layouts

The atmosphere should feel:

- cool
- intelligent
- understated
- slightly mysterious
- technological
- tactile
- urban
- editorial
- immersive

Never childish.

Never excessively nostalgic.

Never retro for the sake of being retro.

---

# 3. DO NOT CONFUSE WITH

Gen X Soft Club is NOT automatically:

- generic Y2K
- cyberpunk
- vaporwave
- synthwave
- Frutiger Aero
- Windows 95 nostalgia
- arcade aesthetics
- hacker UI
- neon sci-fi
- futuristic gaming UI
- chrome-everything
- maximalist 2000s pop
- kawaii futurism
- Matrix imitation

Avoid excessive:

- neon purple
- neon cyan
- hot pink
- holographic gradients everywhere
- chrome typography
- glowing borders
- terminal interfaces
- pixel fonts
- fake code
- random futuristic HUDs

Technology should feel calm, physical and believable.

Think:

glass + concrete + paper + CD + aluminium + fluorescent light.

Not:

neon + spaceship + hacker terminal.

# 6. TYPOGRAPHY

Typography is structural.

Use combinations of:

## Primary

Neo-grotesque / grotesque sans-serif.

Desired feeling:

- Helvetica
- Akzidenz-Grotesk
- Univers
- Swiss / transit typography

Use for:

- major titles
- navigation
- editorial headings
- section names

## Secondary

Monospaced or technical typography.

Use for:

- dates
- archive IDs
- track numbers
- coordinates
- metadata
- system labels
- timestamps

Example:

ARCHIVE_009

1998 / LONDON

TRACK 03

MUSIC / FASHION / CULTURE

Avoid using monospaced fonts for everything.

---

# 7. TYPOGRAPHIC COMPOSITION

Allow typography to become part of the visual composition.

Use:

- oversized headings
- vertical text
- cropped words
- extreme scale differences
- small technical metadata
- wide tracking
- asymmetric alignment
- editorial whitespace
- text partially obscured by images

Example:

GEN X
SOFT
CLUB

Do not force every section into centered headings and standard cards.

# 13. 3D OBJECTS

3D must serve storytelling.

- CD
- MiniDisc

- translucent telephone
- flip phone
- headphones

---

# 14. CURSOR

The native cursor may be replaced on pointer-based devices.

Possible concepts:

- miniature CD
- camera focus marker
- translucent target
- technical crosshair
- interface pointer inspired by late-90s devices

Cursor states should communicate action.

Examples:

[ OPEN ]

[ VIEW ]

[ PLAY ]

[ DRAG ]

[ ENTER ]

Subtle trailing / ghosting is allowed.

Never sacrifice usability.

Touch devices must receive appropriate alternatives.

---

# 15. MOTION

Motion should feel:

- smooth
- physical
- deliberate
- slightly experimental
- cinematic

Good motion:

- slow object rotation
- depth parallax
- photographic focus transitions
- paper movement
- magazine unfolding
- object inertia
- gentle magnetic interaction
- image layering
- controlled scroll sequences

Avoid:

- constant bouncing
- excessive elastic animation
- random motion
- animation on every element
- unnecessary page transitions

Stillness is part of the aesthetic.

---

# 16. IMMERSION

Whenever appropriate, interaction should reinforce the illusion that the user is exploring an archive.

Possible behaviors:

- drag photographs
- rotate objects
- inspect CDs
- unfold newspapers
- move magazine pages
- activate cameras
- answer phones
- interact with music players
- discover hidden articles

The experience may contain Easter eggs.

They must feel intentional and culturally relevant.

---

# 17. SOUND

Sound may enhance immersion.

Possible sounds:

- CD loading
- camera shutter
- MiniDisc mechanism
- button clicks
- subtle electronic feedback
- transport ambience
- room tone

Sound must never become annoying.

Do not unexpectedly blast audio.

Music playback should normally begin after user interaction.

Always provide clear mute / pause controls.

---

# 20. HISTORICAL INTEGRITY

Never invent:

- historical events
- artist quotations
- dates
- album information
- fashion campaigns
- cultural influence
- relationships between artists
- sources
- publications

Distinguish between:

DOCUMENTED HISTORY

and

EDITORIAL / AESTHETIC INTERPRETATION.

If a connection is aesthetic rather than historically documented, present it as an interpretation.

Do not state interpretation as fact.

---

# 21. SOURCES

When historical content is used, maintain source information.

Preferred sources:

- original interviews
- artist archives
- museum archives
- magazine archives
- record label information
- reputable journalism
- design archives
- CARI / Consumer Aesthetics Research Institute
- documented aesthetic research

Moodboards may guide visual direction but should not automatically be treated as historical evidence.

---

# 22. PERFORMANCE

Immersion must not destroy performance.

For 3D:

- optimize geometry
- compress textures
- lazy-load models
- prefer GLB / GLTF
- use appropriate texture sizes
- avoid unnecessary lights
- pause rendering when appropriate

For images:

- responsive images
- modern formats
- lazy loading
- correct sizing

For animation:

- prefer transform and opacity
- avoid layout thrashing
- limit expensive filters
- respect device capabilities

Mobile may use simplified effects.

---

# 23. ACCESSIBILITY

Aesthetic experimentation must not block access.

Always consider:

- keyboard navigation
- visible focus
- semantic HTML
- sufficient contrast
- reduced motion
- screen readers
- touch interaction
- readable typography

Respect:

prefers-reduced-motion

If an interaction only works through hover, provide another method for touch devices.

---

# 24. RESPONSIVE BEHAVIOR

Do not simply shrink desktop layouts.

Desktop may be spatial and highly interactive.

Tablet may simplify depth.

Mobile should become a carefully art-directed vertical experience.

Maintain:

- typography
- photography
- material language
- editorial character

while reducing:

- excessive 3D
- expensive shaders
- complex cursor effects
- unnecessary parallax

---

# 25. ANTI-GENERIC RULE

Before approving any section, ask:

"Could this section exist unchanged on a SaaS website?"

If YES, redesign it.

Avoid default patterns such as:

- generic cards
- gradient blobs
- standard dashboards
- centered hero + CTA
- icon feature grids
- excessive rounded rectangles
- generic glassmorphism
- template-like portfolios

The interface should have cultural identity.

---

# 26. INTERACTION PURPOSE RULE

Before adding an interaction ask:

1. Does it reinforce the Gen X Soft Club world?
2. Does it reveal content?
3. Does it improve navigation?
4. Does it make a digital object feel physical?
5. Does it create meaningful atmosphere?

If none apply, remove the interaction.

---

# 27. DESIGN REVIEW CHECKLIST

Before considering a page complete, verify:

[ ] Does it feel Gen X Soft Club without needing a label?

[ ] Is music culturally and visually important?

[ ] Does fashion feel editorial?

[ ] Is photography treated as a primary design material?

[ ] Are physical objects present where appropriate?

[ ] Does typography contribute to the composition?

[ ] Does interaction have purpose?

[ ] Is the design avoiding generic Y2K?

[ ] Is the design avoiding cyberpunk?

[ ] Are historical claims grounded?

[ ] Does mobile preserve the identity?

[ ] Is performance acceptable?

[ ] Is reduced-motion supported?

[ ] Is navigation understandable?

---

# FINAL PRINCIPLE

Do not design a website ABOUT Gen X Soft Club.

Design a digital place that could belong TO Gen X Soft Club.

The user should not simply understand the aesthetic.

They should enter it.
